# Mumzworld AI Return Reason Classifier

## Overview
AI-powered prototype built for Mumzworld AI Engineering Intern assessment.

This tool classifies customer return messages into:

- Refund
- Exchange
- Store Credit
- Escalate
- Manual Review

Supports English + Arabic output.

## Example

Input:
The stroller arrived damaged and broken.

Output:
- Refund
- استرداد
- Confidence: 0.95

## Tech Stack

- Python
- Streamlit

## Run Project

pip install streamlit

python -m streamlit run app.py

## Features

- Clean UI
- Arabic support
- Confidence score
- Reason explanation
